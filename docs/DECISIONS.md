# Decisions

SPEC section 6 holds the main decisions (D1–D11). This file records every further decision taken during the build, with the reason.

| ID | Decision | Reason |
| --- | --- | --- |
| D-01 | Use the latest stable package versions at build time (Express 5.3, Mongoose 9, Zod 4, Vite 8, React 19, React Router 8, Tailwind 4, Socket.IO 4.8). | SPEC section 3. All share stable APIs with their previous majors for what we use. |
| D-02 | Tailwind v4 with CSS-first config: semantic tokens are CSS variables on `:root` / `.dark`, mapped into Tailwind with `@theme inline`; dark mode is a `.dark` class on `<html>` set before first paint. | One token source, no flash of the wrong theme, components never hard-code light/dark colours. |
| D-03 | Campus centre `13.1718, 77.5362` (Presidency University, Itgalpura, Rajanukunte, Bengaluru). | Best available coordinates; **the user should confirm** and edit `CAMPUS_CENTER_LAT/LNG` in `server/.env` if needed. Only the seed data and map defaults depend on it. |
| D-04 | Flutter is not installed on the build machine, so the mobile app is hand-written: `lib/`, `test/`, `pubspec.yaml`, Android manifests and `MainActivity.kt` are committed; Gradle files and the wrapper are generated by `flutter create .` (documented). | `flutter create` cannot run here. Running it later fills only the missing files, so the committed customisations survive. |
| D-05 | Mobile fonts: static Plus Jakarta Sans TTFs (400/500/700/800) from the official tokotype repository, OFL licence included. | Flutter needs TTF/OTF; @fontsource only ships WOFF/WOFF2. |
| D-06 | Admin user management (`/api/users`) was built in phase 2 instead of phase 3. | Phase 2's "student on admin route → 403" check needs a real admin route. |
| D-07 | Reopening restarts the SLA clock: `slaStartedAt` = reopen time, `dueAt` recomputed, `escalatedAt` cleared. A severity change recomputes `dueAt` from `slaStartedAt`. | A reopened issue is new work; keeping the old deadline would make it instantly overdue and escalate twice for nothing. |
| D-08 | "Hours overdue" in the priority formula counts whole hours (floor). | Keeps priority an integer that changes once per hour, matching the hourly recompute job. |
| D-09 | When a report has both GPS and a scanned room, the room's point is stored. | D9: a room QR gives room-level accuracy indoors where GPS is unreliable. |
| D-10 | Smart assignment falls back to all active technicians (flagged `skillMatch: false`) when nobody has the category skill. | The admin is never left without a suggestion (e.g. category "other" with no specialist). |
| D-11 | Students never see another person's identity: supporters do not see the reporter, and staff entries in the history show only the role. Technicians see the reporter neither. | Minimal disclosure; nobody needs a reporter's name to fix a projector. Admins see everything. |
| D-12 | `clientRequestId` reused by a *different* user → 409 `DUPLICATE` instead of returning that user's issue. | Returning it would leak another student's report. |
| D-13 | CSV export: max 5000 rows, UTF-8 BOM, CRLF, and cells starting with = + − @ are prefixed with a quote. | Excel compatibility and protection against CSV formula injection. |
| D-14 | Day buckets for trends use the campus time zone (Asia/Kolkata). | "Resolved today" must match the wall clock at the booth, not UTC. |
| D-15 | Seed photos are original SVG scenes (one per category, broken and fixed states) rendered by sharp; seed randomness is deterministic. | No stock photos (SPEC 8.1); repeatable demos and screenshots. |
